# 매수 기준 대시보드

5가지 매수 기준을 한 화면에서 확인하는 로컬 웹 대시보드입니다.

> **바로 시작하기**: Python 3.9+ 설치 → 저장소 ZIP 내려받기 → `run.bat`(Windows) 또는 `bash run.sh`(macOS/Linux) 실행. 자세한 방법은 [설치 및 실행](#설치-및-실행)을 보세요.

| # | 기준 | 신호 🟡 | 강한 신호 🟢 | 대상 |
|---|---|---|---|---|
| 1 | 공포·탐욕 지수 (CNN) | 25 미만 | 20 미만 | 시장 |
| 2 | VIX | 25 이상 | 30 이상 | 시장 |
| 3 | RSI(14) — 일봉 30 이하 / 주봉 35 이하 | 하나 해당 | 둘 다 해당 | 종목 |
| 4 | MDD (올해 고점 대비, 종목별 조정) | 종목 연평균 하락률 이하 | 14 : 30 비율로 조정한 구간 이하 | 종목 |
| 5 | 200일 / 200주 이동평균 | 둘 중 하나 아래 | 둘 다 아래 | 종목 |

- S&P 500 MDD와 QQQ MDD(사상 최고가 대비)는 참고용으로 표시하고 점수에는 넣지 않습니다.
- 페이지를 열면 시장 기준(1, 2)이 바로 계산되고, 티커를 검색하면 종목 기준(3~5)이 추가됩니다.
- 미국 티커(`AAPL`, `QQQ`)와 한국 종목코드(`005930`, 코스피 → 코스닥 순서로 자동 조회)를 지원합니다.
- 입력창에 티커·종목코드·영문/한글 이름을 치면 주요 종목 약 120개 중 후보를 미리 보여줍니다(예: `삼성`, `나스닥`, `0059`). ↑/↓ + Enter 또는 클릭으로 바로 조회합니다. 목록은 `static/tickers.json`에 종목을 추가해 늘릴 수 있습니다.

> 투자 판단을 돕는 참고 도구이며 투자 권유가 아닙니다. 데이터는 Yahoo Finance와 CNN의 비공식 경로를 쓰므로 지연되거나 일시적으로 조회되지 않을 수 있습니다.

## 신호 기준 상세

각 카드는 아래 세 단계 중 하나로 판정됩니다. 기준 숫자는 모두 `config.yaml`에서 바꿀 수 있습니다(괄호 안은 설정 키).

| 표시 | 상태 | 의미 |
|---|---|---|
| 🟢 | 강한 신호 | 매수 기준을 강하게 충족 |
| 🟡 | 신호 | 매수 기준을 충족 |
| ⚪ | 중립 | 기준 미충족 |
| ⚠️ | 조회 실패 / 데이터 부족 | 판정할 수 없음 (점수에서 제외) |

### 1. 공포·탐욕 지수 — 시장

- **데이터**: CNN Fear & Greed Index (0~100, 낮을수록 공포)
- **판정**

  | 조건 | 판정 |
  |---|---|
  | 20 미만 (`strong_below`) | 🟢 강한 신호 — 극단적 공포 |
  | 20 이상 25 미만 (`signal_below`) | 🟡 신호 — 공포 |
  | 25 이상 | ⚪ 중립 |

### 2. VIX — 시장

- **데이터**: Yahoo `^VIX` 최근 종가
- **판정**

  | 조건 | 판정 |
  |---|---|
  | 30 이상 (`strong_at_or_above`) | 🟢 강한 신호 — 시장 패닉 |
  | 25 이상 30 미만 (`signal_at_or_above`) | 🟡 신호 — 불안 확대 |
  | 25 미만 | ⚪ 중립 |

### 3. RSI (14) — 종목

- **계산**: 일봉 종가와 주봉 종가(그 주의 마지막 거래일)로 각각 14기간 RSI를 구합니다. Wilder 평활 방식입니다.
- **조건**: 일봉 RSI 30 이하 (`daily_at_or_below`), 주봉 RSI 35 이하 (`weekly_at_or_below`)
- **판정**

  | 일봉 ≤ 30 | 주봉 ≤ 35 | 판정 |
  |---|---|---|
  | 해당 | 해당 | 🟢 강한 신호 |
  | 해당 | 미해당 | 🟡 신호 |
  | 미해당 | 해당 | 🟡 신호 |
  | 미해당 | 미해당 | ⚪ 중립 |

- 상장 기간이 짧아 주봉 RSI를 계산할 수 없으면(약 15주 미만) 일봉만으로 판정하므로 최대 🟡 신호입니다.

### 4. MDD (올해 고점 대비 하락률) — 종목

- **현재 하락률**: `현재 종가 ÷ 올해 최고 종가 − 1`
- **종목별 구간**: 끝난 해마다 "그해 최고점 대비 최대 하락률"을 구해 평균을 냅니다(연평균 최대 하락률, 소수 1자리까지 그대로 사용).
  - 매수 시작 = 연평균 최대 하락률
  - 비중 확대·극단적 하락은 기본 구간 −14 / −30 / −47의 비율을 **남은 가격** 기준으로 적용합니다.
    기본 구간은 남은 가격이 86% → 70% → 53%이고, 70% = 86%를 약 2.37번 곱한 값, 53% = 약 4.21번 곱한 값입니다.
    종목의 남은 가격(1 + 연평균)도 같은 횟수만큼 곱합니다. 그래서 구간이 −100%에 닿지 않습니다.
  - 예: 연평균 −34.1%인 종목 → −34.1% / −62.7% / −82.7%, 연평균 −14%면 기본 구간과 같은 −14% / −30% / −47%
  - 거래일이 200일 미만인 해와 올해는 평균에서 뺍니다(`min_days_per_year`).
  - 끝난 해가 3년 미만이면 기본 구간(−14% / −30% / −47%)을 씁니다(`min_years`).
- **판정**

  | 조건 (기본 구간 기준) | 판정 | 행동 |
  |---|---|---|
  | −14% 이하 (`signal_at_or_below`) | 🟡 신호 | 헷지 자산 일부 매도 → 주식 매수 시작 |
  | −30% 이하 (`strong_at_or_below`) | 🟢 강한 신호 | 헷지 자산 추가 매도 → 비중 확대 |
  | −47% 이하 (`extreme_at_or_below`) | 🟢 강한 신호 + ⚠ 경고 | 극단적 하락 구간 (점수는 강한 신호로 계산) |
  | 그 외 | ⚪ 중립 | 대기 |

- 카드에 연평균 최대 하락률, 52주 고점 대비, 사상 최고가 대비 하락률을 참고로 표시합니다.
- 연초에는 올해 고점을 잡은 기간이 짧아 하락률이 작게 나옵니다.

### 5. 200일 / 200주 이동평균 — 종목

- **계산**: 200일 단순이동평균(일봉 종가), 200주 단순이동평균(주봉 종가). 이격도 = `현재가 ÷ 이동평균 − 1` (`daily_window`, `weekly_window`)
- **판정**

  | 200일선 | 200주선 | 판정 |
  |---|---|---|
  | 아래 | 아래 | 🟢 강한 신호 |
  | 아래 | 위 | 🟡 신호 |
  | 위 | 아래 | 🟡 신호 |
  | 위 | 위 | ⚪ 중립 |

- 상장 약 4년(200주) 미만이면 200일선만으로 판정하므로 최대 🟡 신호입니다. 200일 미만이면 "데이터 부족"입니다.

### 참고: S&P 500 MDD — 시장 (점수 제외)

- **계산**: `^GSPC` 현재 종가 ÷ **사상 최고 종가** − 1 (`market_mdd`)
- 종목별 조정 없이 −14% 매수 시작 / −30% 비중 확대 / −47% 극단적 하락(⚠ 경고) 구간으로 표시하지만 **종합 점수에는 넣지 않습니다**.

### 참고: QQQ MDD — 시장 (점수 제외)

- **계산**: `QQQ`(나스닥100 ETF) 현재 종가 ÷ **사상 최고 종가** − 1 (`qqq_mdd`)
- 첫 신호는 **−20%**(`anchor`), 다음 단계는 S&P 500 단계(−14 / −30 / −47)의 **남은 가격 비율**(86% → 70% → 53%)을 −20%에 맞춰 옮긴 값입니다.

  | 조건 | 판정 |
  |---|---|
  | −20.0% 이하 | 🟡 신호 — 매수 시작 |
  | −41.0% 이하 | 🟢 강한 신호 — 비중 확대 |
  | −60.9% 이하 | 🟢 강한 신호 + ⚠ 극단적 하락 |

- S&P 500 MDD와 마찬가지로 **종합 점수에는 넣지 않습니다**.

### 종합 점수

- 🟡 신호 이상인 기준의 개수를 셉니다. 예: `3 / 5 충족 (강한 신호 1)`
- 처음 열면 시장 기준 2개(1, 2)만으로 `시장 n / 2`, 종목을 검색하면 5개 기준으로 `n / 5`가 됩니다.
- 조회 실패나 데이터 부족인 기준은 분모에서 빼고 `n개 조회 실패`로 따로 표시합니다.
- 각 카드의 `?` 버튼에 마우스를 올리면 그 카드의 판단 기준을 볼 수 있습니다.

## 설치 및 실행

처음 한 번만 **① Python 설치 → ② 내려받기**를 하면, 그다음부터는 **③ 실행 파일 더블클릭**만 하면 됩니다.

### ① Python 설치 (3.9 이상)

이미 설치되어 있는지 먼저 확인하세요. 터미널(Windows는 명령 프롬프트 또는 PowerShell)에서:

```bash
python --version
```

`Python 3.9` 이상이 나오면 ②로 넘어가면 됩니다. macOS / Linux는 `python3 --version`으로 확인하세요.

| OS | 설치 방법 |
|---|---|
| **Windows** | [python.org/downloads](https://www.python.org/downloads/)에서 설치 파일을 받아 실행합니다. 첫 화면 아래의 **"Add python.exe to PATH"를 꼭 체크**하세요. 또는 터미널에서 `winget install Python.Python.3.12` |
| **macOS** | [python.org/downloads](https://www.python.org/downloads/) 설치 파일, 또는 Homebrew를 쓰면 `brew install python` |
| **Ubuntu / Debian** | `sudo apt install python3 python3-venv` (가상환경을 만드는 `python3-venv`도 함께 설치해야 합니다) |

### ② 내려받기

둘 중 편한 방법을 고르세요.

- **ZIP으로 받기 (git 몰라도 됨)**: [GitHub 저장소](https://github.com/0421cjy/buy-signal-dashboard)에서 초록색 **Code → Download ZIP**을 누르고, 받은 파일의 압축을 원하는 폴더에 풉니다.
- **git으로 받기**:

  ```bash
  git clone https://github.com/0421cjy/buy-signal-dashboard.git
  ```

### ③ 실행

| OS | 실행 방법 |
|---|---|
| **Windows** | 압축을 푼 폴더에서 `run.bat`을 **더블클릭** |
| **macOS / Linux** | 터미널에서 폴더로 이동한 뒤 `bash run.sh` |

실행 파일이 알아서 다음을 처리합니다.

1. 프로젝트 폴더 안에 전용 가상환경(`.venv` 폴더)을 만듭니다. 컴퓨터의 다른 Python 환경에는 영향을 주지 않습니다.
2. 필요한 패키지(`requirements.txt`)를 설치합니다. **처음 실행할 때만 1~3분 정도** 걸리고, 다음부터는 몇 초면 됩니다.
3. 서버를 켜고 브라우저에서 `http://127.0.0.1:8000`을 엽니다.

- **종료**: 실행 창에서 `Ctrl + C`를 누르거나 창을 닫으면 됩니다.
- **다시 실행**: 같은 실행 파일을 다시 더블클릭하면 됩니다.
- 서버는 내 컴퓨터(`127.0.0.1`)에서만 접속할 수 있고, 외부에 공개되지 않습니다.

### 업데이트

- **ZIP으로 받은 경우**: 새 ZIP을 받아 압축을 풀고 실행합니다. `config.yaml`을 고쳐 썼다면 새 폴더에 옮겨 주세요.
- **git으로 받은 경우**: 폴더에서 `git pull` 후 실행합니다.

실행 파일이 매번 패키지를 확인하므로 새로 필요한 패키지도 자동으로 설치됩니다.

### 문제 해결

| 증상 | 해결 |
|---|---|
| `Python 3.9+ is required` / `python을 찾을 수 없음` | ①을 다시 확인하세요. Windows는 설치할 때 "Add python.exe to PATH"를 체크하지 않았다면 Python을 다시 설치하면서 체크하세요. |
| Windows에서 실행하면 **Microsoft Store가 열리거나** 가상환경을 만들다 실패 | Windows의 가짜 `python` 바로가기 때문입니다. **설정 → 앱 → 고급 앱 설정 → 앱 실행 별칭**에서 `python.exe`, `python3.exe`를 끈 뒤, python.org에서 설치하세요. |
| Ubuntu에서 `ensurepip is not available` | `sudo apt install python3-venv`를 설치한 뒤 프로젝트 폴더의 `.venv` 폴더를 지우고 다시 실행하세요. |
| `pip install failed` | 인터넷 연결을 확인하세요. 회사·학교 네트워크라면 보안 정책으로 막혀 있을 수 있습니다. `.venv` 폴더를 지우고 다시 실행해 보세요. |
| 포트 8000이 이미 사용 중이라는 오류 | 이미 실행 중인 창이 있는지 확인하세요. 다른 프로그램이 8000번을 쓴다면 `config.yaml`의 `server: port:` 값을 `8080` 등으로 바꾸세요(실행 창의 안내 문구는 8000으로 나오지만, 브라우저는 바꾼 포트로 열립니다). |
| 카드에 "조회 실패"가 뜸 | 인터넷 연결을 확인하고 새로고침을 눌러 보세요. Yahoo / CNN 쪽이 일시적으로 응답하지 않을 때도 있습니다. |
| 화면이 이전 모습 그대로 | 업데이트 후라면 브라우저에서 `Ctrl + F5`(macOS는 `Cmd + Shift + R`)로 새로고침하세요. |

## 기준 바꾸기

`config.yaml`의 숫자를 고치고 다시 실행하면 됩니다. 지표를 끄려면 `enabled: false`로 두세요.

- 화면을 띄워 두면 **10분마다 자동 새로고침**합니다(`auto_refresh_minutes`, `0`이면 끔). 탭이 숨겨져 있는 동안은 건너뛰고, 다시 보일 때 간격이 지났으면 바로 갱신합니다.
- 서버는 받은 데이터를 10분 동안 저장해 둡니다(`cache_ttl_seconds`). 새로고침 버튼과 자동 새로고침은 저장된 값을 무시하고 새로 받습니다.

## 지표 추가하기

1. `app/indicators/`에 파일을 하나 만듭니다.
2. `Indicator`를 상속하고 `@register`를 붙입니다.

```python
from app.indicators.base import NEUTRAL, SIGNAL, Indicator, register

@register
class MyIndicator(Indicator):
    id = "my_indicator"     # config.yaml의 indicators 아래 키
    name = "내 지표"
    scope = "ticker"        # "market"(실행 즉시) 또는 "ticker"(검색 시)
    scored = True           # False면 참고용 카드
    order = 70              # 화면 표시 순서

    def evaluate(self, ctx):
        s = ctx.get_daily(ctx.symbol)
        value = float(s.iloc[-1])
        status = SIGNAL if value < ctx.config["below"] else NEUTRAL
        return self.make(status=status, value=value, display=f"{value:.2f}")
```

3. `config.yaml`의 `indicators:` 아래에 `my_indicator: { enabled: true, below: 100 }`을 추가합니다.

화면은 결과를 받아 카드를 자동으로 그립니다.

## 개발

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-dev.txt   # macOS/Linux: .venv/bin/python
.venv/Scripts/python -m pytest            # 네트워크 없는 테스트
.venv/Scripts/python -m pytest -m live    # 실제 데이터 조회 스모크 테스트
```
